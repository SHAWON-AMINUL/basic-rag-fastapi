# Basic RAG API with FastAPI

A beginner-friendly **Retrieval-Augmented Generation (RAG)** project built with **FastAPI, LangChain, BGE-M3, PostgreSQL, and pgvector**.

This project demonstrates how to load documents, split them into chunks, convert text into vector embeddings, store them in a vector database, and retrieve relevant information through semantic search.

## 🚀 Features

* **FastAPI:** REST API for interacting with the RAG pipeline.
* **LangChain:** Document processing, text splitting, and retrieval integration.
* **BGE-M3:** Text embedding model for semantic representation.
* **PostgreSQL + pgvector:** Vector storage and similarity search.
* **Document Ingestion:** Load and process `.txt` files.
* **Semantic Search:** Retrieve relevant document chunks based on user questions.
* **Docker Compose:** Easy PostgreSQL and pgvector setup.
* **Interactive API Docs:** Test endpoints using Swagger UI.

## ⚙️ Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/basic-rag-fastapi.git
cd basic-rag-fastapi
```

### 2. Create a virtual environment

```bash
python -m venv venv
```

Activate it on Windows PowerShell:

```powershell
.\venv\Scripts\Activate.ps1
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Start PostgreSQL with pgvector

Make sure Docker Desktop is running.

```bash
docker compose up -d
```

### 5. Configure environment variables

Create a `.env` file in the project root.

```env
DATABASE_URL=postgresql+psycopg://rag_user:rag_password@localhost:5432/rag_db
EMBEDDING_MODEL=BAAI/bge-m3
```

Use your own database credentials if you change the Docker Compose configuration.

### 6. Add documents

Place your `.txt` files inside the `documents/` folder.

### 7. Ingest documents

```bash
python -m app.ingest
```

This command loads documents, splits them into chunks, generates embeddings, and stores them in PostgreSQL.

### 8. Run the FastAPI server

```bash
uvicorn app.main:app --reload
```

The API will be available at:

* API: http://127.0.0.1:8000
* Swagger UI: http://127.0.0.1:8000/docs
* Health Check: http://127.0.0.1:8000/health

| GET    | `/health` | Health check                          |

### Example Request

**POST** `/chat`

```json
{
  "question": "What are the admission requirements?"
}
```

The endpoint returns the result generated by the RAG pipeline.

## 🧠 How RAG Works

1. **Load:** Read text documents from the knowledge base.
2. **Split:** Divide documents into smaller chunks.
3. **Embed:** Convert each chunk into a numerical vector using BGE-M3.
4. **Store:** Save the vectors and document chunks in PostgreSQL with pgvector.
5. **Retrieve:** Convert a user's question into an embedding and search for similar document chunks.
6. **Generate:** Use the retrieved context in the RAG pipeline to produce a response.
